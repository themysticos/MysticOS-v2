# MysticOS 2

**MysticOS 2** — 32-битная hobby-ОС для x86 с графическим интерфейсом,
написанная на C и NASM. Работает в защищённом режиме, использует VBE
(800x600x24bpp), собственный оконный менеджер, кооперативную
многозадачность и ELF-программы.

> Актуальная версия проекта. Первая (текстовая) версия — см. **MysticOS v1**
> (заброшена, только крупные багфиксы).

## Возможности

- **Графика** — VBE 800x600x24bpp, двойная буферизация, свой шрифт 8x8,
  примитивы (линии, прямоугольники, заливка), PNG-иконки (ARGB).
- **Оконный менеджер** — перемещение, z-порядок, кнопки min/max/close,
  таскбар, меню Пуск, рабочий стол с иконками, курсор мыши (PS/2).
- **Обои рабочего стола** — BMP 24/32bpp, растягиваются на весь экран;
  смена через программу выбора (`WPICK.ELF`).
- **Кооперативная многозадачность** — per-task адресное пространство
  (paging, PSE 4 МБ), физический аллокатор (pmem), переключение контекста.
- **ELF-загрузчик** — программы грузятся как отдельные задачи.
- **Собственный API** (`api.h`) для ELF-программ: окна, рисование,
  ввод, ФС, обои, картинки.
- **VFS** (`vfs.c`, `fs.h`) — единый слой поверх драйверов ФС
  с поддержкой букв дисков (`D0:`, `D1:`).
- **FAT12/FAT16** (`fat.c`) — чтение каталогов, чтение/запись файлов,
  подкаталоги, два диска ATA.
- **Системные программы** (`examples/`):
  - `FILES.ELF` — файловый менеджер в стиле Проводника;
  - `EDITOR.ELF` — текстовый редактор (F2/Ctrl+S — сохранить);
  - `IMGVIEW.ELF` — просмотрщик BMP;
  - `WPICK.ELF` — выбор обоев;
  - `TERM.ELF` — терминал;
  - `ABOUT.ELF` — окно «О системе».

## Сборка

Требуется Linux/WSL (или MSYS2) с инструментами:

- `nasm`
- `gcc` (с `-m32`, т.е. gcc-multilib)
- `ld`, `objcopy` (binutils)
- `mkfs.fat` (пакет `dosfstools`)
- `python3` (утилиты в `tools/`)
- `qemu-system-x86_64` (для запуска)

Сборка и запуск:

```sh
make          # собрать mysticos2.img (+ disk2.img)
make run      # запустить в QEMU (два диска)
make clean    # очистить артефакты
```

Запуск вручную:

```text
qemu-system-x86_64 -drive format=raw,file=mysticos2.img,if=ide,index=0 \
                   -drive format=raw,file=disk2.img,if=ide,index=1 -m 256
```

## Структура

| Файл                 | Назначение                                   |
|----------------------|----------------------------------------------|
| `bootloader.asm`     | загрузчик (реальный режим, VBE)              |
| `entry.asm`          | точка входа ядра (protected mode)            |
| `linker.ld`          | скрипт линковки                              |
| `kernel.c`           | ядро: рабочий стол, окна, API, меню          |
| `vbe.c`/`vbe.h`      | framebuffer, двойная буферизация, примитивы  |
| `bmp.c`/`bmp.h`      | декодер BMP 24/32bpp с масштабированием      |
| `vfs.c`/`fs.h`       | слой виртуальной ФС (D0/D1)                  |
| `fat.c`/`fat.h`      | драйвер FAT12/FAT16 (два диска)              |
| `task.c`/`switch.asm`| кооперативная многозадачность                |
| `paging.c`/`pmem.c`  | страничная адресация и физ. аллокатор        |
| `exec.c`             | ELF-загрузчик                                |
| `idt.c`/`pic.c`      | прерывания, PIC, PIT, клавиатура, мышь       |
| `icons.c`            | иконки (спрайты + процедурные)               |
| `examples/`          | системные ELF-программы                      |
| `tools/`             | утилиты сборки образа                        |

## Статус

Активная разработка. Графическая оболочка, оконный менеджер, обои,
файловый менеджер, редактор и просмотрщик — работают. В планах: MSFS,
улучшение UX, новые драйверы ФС.
